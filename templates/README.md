# Editable templates

Open a file ending in `-editable.svg` in an SVG-capable design application. Install the fonts from `typography/` first. Supporting text remains editable where present; the logo remains vector paths to preserve the approved lettering.

Keep `templates/`, `illustrations/` and `typography/` in their repository structure. Editable templates link to the shared watercolor backgrounds instead of duplicating large image data. Their exported counterparts contain embedded artwork and outlined text for reliable sharing.

- `open-markets-podcast-cover-editable.svg`: 3000 × 3000.
- `podcast-title-editable.svg`: 1920 × 1080, adaptable for an episode title.
- `square-editable.svg`: 1080 × 1080.
- `link-preview-editable.svg`: 1200 × 630.
- `story-editable.svg`: 1080 × 1920.
- `hero-editable.svg`: 1152 × 1152 square artwork wrapper; no text or cropping. Use the original WebP directly on the website.
- `presentation-title-editable.svg`: 1920 × 1080 presentation opener.

Change text to match the actual episode or event and check line lengths after editing. Do not add unverified guest, speaker, partner or sponsor information.
