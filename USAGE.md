# Rights and asset status

This repository packages the watercolor identity derived from the approved concept board. SVG/PDF logo masters, transparent PNGs, templates and media exports are provided alongside the unchanged original homepage illustration. The rejected replacement scenes and outdated concept board are removed from current downloads.

Font files are distributed under the SIL Open Font License included with each family. That font license does not license the foundation's name, logos or artwork. No open-source or trademark license for those assets is granted by this repository. Use the official website for current organizational information and contact routes for rights questions.

The original monochrome and neon artwork is preserved in `archive/` as historical reference. It is not the current visual identity.
