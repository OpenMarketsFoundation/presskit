# Typography

The website stylesheet declares **Merriweather** for serif headings and **Manrope** for body text. Verified against [the public stylesheet](https://openmarkets.pub/_nuxt/entry.Cme9mKLK.css) on 24 October 2026.

- [Merriweather variable font](Merriweather/Merriweather-Variable.ttf) / [SIL Open Font License](Merriweather/OFL.txt)
- [Manrope variable font](Manrope/Manrope-Variable.ttf) / [SIL Open Font License](Manrope/OFL.txt)
- [All fonts and licenses](fonts.zip)

Official distribution sources: [Merriweather](https://github.com/google/fonts/tree/main/ofl/merriweather) and [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope).

Install the variable fonts for editing. Static instances in `static/` support tools that cannot use variable fonts: Merriweather 700, Manrope 400 and Manrope 600. Install one font set at a time to avoid duplicate family entries. Preserve the license files when redistributing fonts.

The custom outlined logo lettering is traced from the approved concept. These font families are used for supporting text, not to substitute for the wordmark.
